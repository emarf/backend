# Reference solutions — module 2

Files here mirror `api/`:

```
prisma/schema.prisma                 tasks 01, 05, 06, 07
prisma/migrations/0_init             task 02 — the SQL that created the existing database
prisma/migrations/*_ticket_constraints  task 04 — written by hand (--create-only)
prisma/migrations/*_tickets_cascade     task 05 — generated by prisma migrate dev
prisma/migrations/*_artists             task 06 — generated
prisma/migrations/*_orders_paid_at      task 07 — generated ADD COLUMN + backfill and CHECKs by hand
src/database/                        task 03 — PrismaService, provided next to Pool
src/users/users.service.ts           task 03
src/orders/orders.service.ts         tasks 07 and 08 (the controller calls `create` and `pay`)
```

Open them only after your own version passes `pnpm test:schema` and `pnpm test:api`.
Your migration folder names will have other timestamps — that is expected.
